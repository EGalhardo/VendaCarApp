Como a deteção funciona

  1. Um só HTML/CSS/JS — sem frameworks, sem CDN. As imagens do catálogo estão embutidas, por isso funciona offline e abre com duplo clique.
  2. Media queries — acima de 900 px o layout é grid de 2 colunas (barra lateral fixa de 250 px + conteúdo). A 1080 px ou menos a barra colapsa para ícones.
  3. Em mobile — a mesma marcação passa a: faixa verde no topo (marca Modelo), appbar fixa com voltar/título, conteúdo em coluna única e navbar com Modelos · Orçamentos · Clientes · Perfil.
  4. Mesmos fluxos nos dois modos — criar modelo com até 6 fotos (1ª = capa), detalhe com galeria, popup Adicionar Carro pré-preenchido, orçamento com entrada editável e envio para wa.me/244….
  5. Persistência — o estoque (incluindo fotos carregadas) fica no localStorage; sobrevive a recarregamentos do navegador.
Testado de ponta a ponta nos dois modos: criar modelo com imagens → detalhe → orçamento (288.000 Kz / 12x 24.000 Kz) → WhatsApp (wa.me/244923456789) → separadores → filtros e busca → persistência após reload. Sem erros de consola.
